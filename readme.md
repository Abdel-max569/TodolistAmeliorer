# 📝 To-Do List App

Une application web simple et intuitive pour gérer vos tâches quotidiennes. Ce projet permet d'ajouter, modifier, supprimer et filtrer des tâches tout en les sauvegardant localement dans le navigateur.

## 🚀 Fonctionnalités

- **Gestion des tâches** : Ajouter, modifier et supprimer des tâches.
- **Priorités** : Définir des niveaux d'importance (Basse, Moyenne, Urgente).
- **Statut en temps réel** : Marquer une tâche comme terminée en un clic.
- **Filtrage avancé** : Rechercher par mot-clé ou filtrer par statut (En cours, Terminées, Urgentes).
- **Tableau de bord** : Compteurs automatiques pour suivre le nombre de tâches par catégorie.
- **Persistance des données** : Utilisation du `localStorage` pour ne pas perdre vos données après actualisation.

## 🛠️ Technologies utilisées

- **HTML5** : Structure de l'application.
- **CSS3** : Design moderne et responsive.
- **JavaScript (Vanilla)** : Logique de l'application et manipulation du DOM.
- **FontAwesome** : Icônes interactives.

## 📂 Structure du projet

- `index.html` : Contient la structure de la page et les menus.
- `style.css` : Gère l'apparence visuelle (mise en page, couleurs, boutons).
- `script.js` : Contient toute la logique (stockage, recherche, affichage).

## 📖 Comment l'utiliser ?

1. Clonez ou téléchargez le projet.
2. Ouvrez le fichier `index.html` dans n'importe quel navigateur.
3. Saisissez le nom d'une tâche, choisissez sa priorité et sa date, puis cliquez sur **Ajouter**.
4. Utilisez la barre de recherche en haut pour retrouver rapidement une tâche précise.
